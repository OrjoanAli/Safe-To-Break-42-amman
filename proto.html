Prototype pollution

What it is

CWE-1321 · OWASP A08:2021 Software and Data Integrity Failures

Almost every JavaScript object inherits from one shared object, Object.prototype. If user input can write into it, every object in the app suddenly has the attacker’s property. The page then believes a normal guest is an admin, and no user record was ever edited.

The line

Danger: vulnerable version
        
function parseQuery(query) {

        
  const config = {};

        
  for (let pair of query.slice(1).split("&")) {

        
    let [rawKey, val] = pair.split("=");

        
    let cleanKey = rawKey.replace("__proto__", "");

        
    let keys = cleanKey.replace(/\]/g, "").split("[");

        
    let curr = config;

        
    for (let i = 0; i < keys.length - 1; i++) {

        
      if (!curr[keys[i]]) curr[keys[i]] = {};

        
      curr = curr[keys[i]];

        
    }

        
    curr[keys[keys.length - 1]] = (val === "true"); causes the bug

        
  }

        
  return config;

        
}

      
        
function parseQuerySafe(query) {

        
  const config = Object.create(null);

        
  const blocked = ["__proto__", "constructor", "prototype"];

        
  for (let pair of query.slice(1).split("&")) {

        
    let [rawKey, val] = pair.split("=");

        
    let keys = rawKey.replace(/\]/g, "").split("[");

        
    if (keys.some(k => blocked.includes(k))) continue; the fix

        
    let curr = config;

        
    for (let i = 0; i < keys.length - 1; i++) {

        
      if (!curr[keys[i]]) curr[keys[i]] = Object.create(null);

        
      curr = curr[keys[i]];

        
    }

        
    curr[keys[keys.length - 1]] = (val === "true");

        
  }

        
  return config;

        
}

Highlighted line 12: the parser writes into whatever object curr points to. A key path like constructor, prototype, or a __proto__ that the filter rebuilds by accident, makes curr point to Object.prototype, so the write lands on every object in the app.

Highlighted line 7: any key named __proto__, constructor or prototype is skipped before anything is written. Object.create(null) also makes objects that have no prototype chain to pollute.

Why it matters

Polluting Object.prototype lets an attacker raise their own privileges, skip client-side security checks, or reach dangerous code such as DOM XSS when a polluted value flows into it. In 2019 a prototype pollution bug in the Lodash library (CVE-2019-10744, in the defaultsDeep function) affected millions of web applications.
